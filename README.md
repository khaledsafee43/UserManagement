# User Management System

A full-stack User Management System built with **React.js, Node.js, and Express.js**.

The application provides a clean interface for managing users with **CRUD operations**, RESTful API integration, user search, editing, deletion, and real-time data handling between the frontend and backend.

### Tech Stack

* React.js
* JavaScript
* Node.js
* Express.js
* REST API
* CSS / Tailwind CSS

### Features

* Create users
* View users
* Search users
* Edit user information
* Delete users
* RESTful API integration
* Frontend and backend communication
* Responsive user interface
